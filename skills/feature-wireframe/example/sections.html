Summary

What this adds

Admins and billing staff can download the invoices they're looking at as a CSV file, with the same filters the page shows.

It starts on the Invoices page. Viewers don't get it, the same way they don't get New invoice today. There are two design choices: where the button lives, and whether to confirm first.

    New in this featureRemoved1See the note with that number

    Invoices list

    Where it starts. Shown with option A from the next choice; the states show what changes by role and when nothing matches.

    1. Download CSV sits next to New invoice, as a plain button so New invoice stays the main action.
    2. The file follows these filters: status, search and date range. What you see is what you get.
    3. Disabled when nothing matches, with a hover hint: "No invoices to download with these filters."
    4. Viewers see no button, the same rule that hides New invoice and Actions today.

    Design choice

    Where does the download start?

    Both use what the page already has: header buttons, or the Actions menu that holds Send reminders and Mark as paid.

    Design choice

    Confirm first, or download straight away?

    Downloading changes nothing, so a confirmation is only there to show which filters apply.

    After downloading

    What the person sees once the file is made, when it's slow, and when it fails.

    1. The toast gives the count, using the app's usual bottom-right toast.
    2. Over 5,000 rows, a banner shows while the file is made; the button waits until it's done.
    3. A failure says what happened and offers Try again; nothing is half-downloaded.

    Questions to settle

    • DecideShould the file include customer email? Useful for chasing payments, but it puts personal data in a file that gets emailed around.
    • DecideOne row per invoice, or one row per line item? Line items would need a second file or a much wider one.
    • AssumedBilling staff get the button as well as admins, because they can already create invoices.
    • AssumedOver 5,000 rows the file is made in the background; under that it downloads at once.
