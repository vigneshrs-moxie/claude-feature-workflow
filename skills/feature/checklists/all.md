# Every step

- Read the repo's `AGENTS.md` / `CLAUDE.md` before writing code. Match the surrounding code's naming, structure and comment density.
- Change only what this plan step needs. Unrelated cleanups go in your report as suggestions.
- Tests for this step come from the test plan; add them alongside the code.
- Run only the approved read-only checks.
- User-facing text appears exactly as the spec words it. Where the spec gives no wording, propose it in your report rather than inventing final copy.

**Orbit**
- Local checks (from `app/`, in the task worktree): `npm run typecheck`, `npm run lint`, `npm test` (Vitest, `src/**/*.test.{ts,tsx}`), or `npm run check` for all three; plus `npm run build` before PR #1, as the git workflow requires.
- `npm run test:db` syncs and writes the test database: it needs a separate yes.
- The `AGENTS.md` Next.js block is regenerated by `next dev`. If it shows up in your diff, commit it with your work rather than deleting it.
